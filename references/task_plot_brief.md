# Task Plot Brief

Task: Lexical Decision Task
Construct: lexical access / visual word recognition

## Required Rows

- High-frequency word: fixation (500 ms) -> HOUSE (up to 2000 ms; F = Word) -> blank ITI (150 ms).
- Low-frequency word: fixation (500 ms) -> THIMBLE (up to 2000 ms; F = Word) -> blank ITI (150 ms).
- Pseudoword: fixation (500 ms) -> CEMORE (up to 2000 ms; J = Nonword) -> blank ITI (150 ms).
- Wrong key: fixation (500 ms) -> HOUSE with J response -> ERROR (750 ms) -> blank ITI (150 ms).

## Visual Contract

- Every participant-screen snapshot is a black rectangle.
- Fixation is one centered white plus.
- Letter strings are one centered uppercase white monospace string, with no fixation simultaneously visible.
- Error feedback is one centered red `ERROR` label.
- Blank ITI screens contain no visible stimulus.
- Use only the exact strings `HOUSE`, `THIMBLE`, and `CEMORE`; do not turn the pseudoword into a real word.
- The F key always means Word; the J key always means Nonword.
- Correct trials do not show feedback. Only the wrong-key row shows ERROR.
- Leave the top 15-18% blank for the TaskBeacon title and logo overlay.
